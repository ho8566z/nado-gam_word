## 제작 방식(안)

- **도구**: python-pptx로 도형·텍스트를 직접 그려 만든다(샘플처럼 이미지가 아닌 편집 가능한 도형). 화면 캡처만 이미지.
- **비율·크기**: 16:9, 20×11.25in(샘플과 같음). 샘플 레이아웃(라벨 + 큰 제목 + 카드)을 그대로 따른다.
- **색**: 사이트와 같은 포인트 `#ff5a36`(주) + `#2f3dff`(보조), 글자 `#1b2236`, 배경 흰색/`#f7f4ef`. (샘플의 파랑 포인트를 우리 색으로 교체)
- **공통 틀**: 상단 작은 영문 라벨(예: BENCHMARK) → 큰 한글 제목 → 카드·표 본문 → 하단 출처/주석. 구분 슬라이드(3·10·24번)는 큰 숫자 + 파트명.
- **확인**: 만든 뒤 PDF로 변환해 장마다 눈으로 점검(글자 넘침·겹침).

## 제작 진행 (2026-11-21)

- 결정: 단계별 확인 방식 → 샘플 5장 확인 후 **36장 전체 생성 완료**. 표지는 마스코트 대신 **메인 지구본 화면**(captures/cover_hero.png)으로 교체. 마스코트는 Q&A 슬라이드에 사용.
- 산출물: `나도감_발표.pptx`(36장, 20×11.25in), 생성 스크립트 `build_ppt.py`(문구를 고치고 `python build_ppt.py all` 로 다시 생성), 화면 캡처 `captures/`(16장 + 마스코트·표지 이미지).
- 숫자는 명세서 스크립트·schema.sql·테스트 결과에서 읽어 온다(요구 78·기능 43·화면 104행·API 52·테이블 25·테스트 149).

- 알려진 차이: 엑셀 WBS 시트에는 3.27(성공 색 수정)이 없고 PPT·노션에는 있다(PPT는 '3.1~3.27'로 표기).
- (11/21 수정) 표지 지구본의 어두운 배경을 제거해 투명 PNG(`captures/cover_globe.png`, build_ppt.py 가 캡처에서 자동 생성)로 교체. 전체 배경을 진한 모래색(#e9e1d2)으로, 카드는 흰색+테두리로 바꿔 대비를 키우고, 파트별 왼쪽 색 띠(PART 1 주황·2 파랑·3 남색)와 모서리 장식 원을 추가.
- (11/21 2차 수정, 38장) 사용자 요청: ① 주제 선정 배경을 "그냥 여행이 가고 싶었다"로 변경(직접 입력 상자 제거) ② 벤치마킹을 샘플 PPT처럼 사이트별 3장(하나투어·트립닷컴·놀유니버스, 주요 기능·참고한 점·다른 점·출처)으로 교체(공개 정보를 웹 검색으로 확인, 모두투어는 각주) ③ 배경을 하늘색→노을빛 그라데이션 + 해·구름 장식으로 변경(여행을 기대하는 느낌). 슬라이드 번호가 2장씩 밀림(PART 2 구분=12, PART 3 구분=27).

## 최종본 (2026-11-21)

- **사용자가 PowerPoint에서 직접 마무리한 `나도감_발표.pptx`(32장)가 최종본이다.** 생성 스크립트가 만든 34장 초안과 다르다.
- `build_ppt.py`는 **초안 생성용**이다. 다시 실행하면 최종본이 덮어써지므로 실행하지 않는다(필요하면 다른 파일 이름으로 저장해 비교).
