# nado_gam (나도 감) 기능 정의서

> 4차 개인 프로젝트: 여행사(항공편 중심) 웹사이트
> 작성일: 2026-11-19 / 개정: 2026-11-20 (추가 요구사항 반영, 마감 11/25) / 상태: 초안 (사용자 확인 대기)

## 1. 확정 사항

| 항목 | 결정 |
|---|---|
| 기술 스택 | Spring Boot(Java) + Spring Security + JPA + MySQL + **Thymeleaf + JS** |
| 지구본 효과 | JS 라이브러리(후보: globe.gl) |
| 출발지 | **여행지를 먼저 고르면 그 여행지로 가는 항공편이 있는 출발지만 목록에 표시** (확정 11/19). 한국발은 인천/김포/김해, 서울·부산 도착은 해외 도시가 출발지 |
| 한국→일본 | 한국 3개 공항(인천·김포·김해) × 일본 4개 도시(도쿄·오사카·후쿠오카·삿포로) **12개 조합 모두 운항** |
| 관리자 분리 | **한 앱, 경로 분리** (`/admin/**` vs 일반 경로) |
| DB | 관리자 영역과 사용자 영역 테이블을 구분 (`02_DB설계서.md` 참고) |
| 가격 기준 | 편도, 성인 1인, 원화(KRW) |
| 예약·결제 | **장바구니 + 모의 결제** (11/20 확정). 장바구니에 담고 결제 버튼을 누르면 "결제되었습니다" 안내 후 마무리한다. 실제 결제 서비스는 쓰지 않는다. (구현 방식 세부는 2-13) |
| 일정 | 마감 **11/25** (기존 11/22에서 연장) |
| 포인트 색 | **오렌지**(배경은 어두운 톤 유지) |
| 마스코트 | 코뿔소 **거코** + 머리 위에서 불을 뿜는 병아리 **삐삐** (SVG 직접 제작) |
| 모바일 | 별도 `/m` 없이 **반응형 + 모바일 하단 탭 바** |
| 가상 데이터 | 항공사·호텔·크루즈·투어 브랜드·상품 이름은 모두 가상. 웹 조사는 참고만 한다. |

## 2. 사용자 웹 (메인 = 대시보드)

상단 메뉴 7개로 구성한다. (11/20 개정: 4개 → 7개)

```
[ 거코·삐삐 nado_gam ]  해외 여행 | 국내여행 | 투어 | 이달의 특별기획 | 베스트셀러 | 고객문의 | 계정   [장바구니] [로그인/로그아웃]
```

- 호텔과 크루즈(배 이동편)는 독립 메뉴 없이 **해외 여행 안**에서 여행지를 고른 뒤 항공편·크루즈·호텔 탭으로 선택한다.
- 휴대폰 폭에서는 상단 메뉴를 접고 **하단 탭 바**(홈·여행·투어·장바구니·내 정보)를 보여준다.

### 2-1. 계정 (`/account`)

| 기능 | 설명 |
|---|---|
| 조회 | 아이디, 이름, 전화번호, 이메일, 가입일 표시 (비밀번호는 표시하지 않음) |
| 수정 | 이름, 전화번호, 이메일, 비밀번호 변경 (비밀번호 변경은 현재 비밀번호 확인) |
| 삭제 | 회원 탈퇴. 탈퇴 확인 단계를 둔다. 데이터는 `status=WITHDRAWN` 으로 보존(소프트 삭제) |
| 비로그인 | 로그인 페이지로 이동 |

### 2-2. 해외 여행 (`/travel`)

흐름: **여행지 선택 → 출발지 선택 → 직항/경유 선택 → 항공편 목록 → 상세**

1. 여행지 선택 (**50개 도시**. 지도/카드/목록 중 선택)
   - 블라디보스토크는 **'운항 불가'** 배지로 표시하고 선택할 수 없다. 사유: 전쟁·제재로 직항 운항 중단
2. **출발지 선택**: 선택한 여행지로 가는 항공편이 있는 출발지만 목록에 띄운다. (항공편 데이터의 출발 공항을 중복 없이 모아서 표시)
   - 일본(도쿄·오사카·후쿠오카·삿포로): 인천, 김포, 김해 모두 표시
   - 유럽·미주·중동·아프리카·오세아니아·중국·태국 등: 인천만 표시
   - 서울: 도쿄(하네다), 로스앤젤레스, 방콕 / 부산: 오사카, 후쿠오카, 도쿄(나리타)
   - 출발지가 1개뿐이면 자동 선택하고 다음 단계로 넘어간다.
3. **지구본 효과**: 출발지에서 도착지로 이어지는 비행 궤적 호(arc)를 3D 지구본에 그린다.
   - 직항: 출발 → 도착 호 1개
   - 경유: 출발 → 경유지 → 도착 호 2개 (경유지에 점 표시)
   - 항공편 카드에 마우스를 올리면 해당 항공편의 경로를 강조한다.
4. **직항 / 경유 선택** 필터 (전체 / 직항만 / 경유만)
5. 항공편 목록 (정렬: 가격순, 소요시간순, 출발시각순)
6. 항공편 상세: 좌석등급별 가격, 수하물, 기내식, 기종, 경유지 정보

### 2-3. 이달의 특별기획 (`/special`, `/special/{planId}`)

- **기획전 3곳 (확정 11/19)**: 로마, 삿포로, 케이프타운 (기간 2026-11-01 ~ 2026-12-31). 기획전마다 항공편 3편.
- `/special` 은 기획전 3개를 카드로 보여주고, 카드를 누르면 `/special/{planId}` 상세로 넘어간다.
- 상세: 기획전 머리글(포스터), 항공편 카드(출발·도착·소요·경유지), 좌석등급별 정가 취소선·특가·할인율·특가 좌석 수
- 마케팅 구성: 배너 문구, 정가 취소선과 특가, 할인율 배지, 마감 카운트다운(D-day), 추천 포인트 3줄

### 2-4. 베스트셀러 (`/bestseller`, `/bestseller/{destinationId}`)

- **베스트셀러 3곳 (확정 11/19)**: 도쿄, 로스앤젤레스, 홍콩. 여행지 판매 합계 순으로 1~3위를 매긴다(도쿄 4,240, 로스앤젤레스 2,450, 홍콩 2,260).
- 카드를 누르면 그 여행지의 순위 항공편 목록으로 넘어간다. 도쿄는 5편, 로스앤젤레스와 홍콩은 3편이다. 항공편 순위는 여행지 안에서 매긴다.
- 순위 배지, 누적 판매 수, 일반석 최저가, 좌석등급별 가격을 표시한다.
- 판매량은 더미 값으로 시작하고, 예약 기능(2단계)이 생기면 실제 예약 수로 집계한다.

### 2-5. 메인 페이지 (대시보드, `/`) — 구현 완료 (11/19)

위에서 아래로 세 부분으로 구성한다.

| 구역 | 내용 |
|---|---|
| 히어로 | 화면 가운데에서 **천천히 도는 지구본**. 인천에서 세계 각지로 **비행기가 날아가고**(최대 7대), 경로는 흐르는 점선, 기획전·베스트셀러 여행지는 노란색과 이름표로 강조한다. 지구본은 끌어서 돌릴 수 있다. |
| 이달의 기획전 | 포스터 카드 3장 **캐로셀** (한 장씩 큰 카드) |
| 베스트셀러 | 포스터 카드 3장 **캐로셀** (한 장씩 큰 카드) |

- **포스터 카드**: 사진 대신 CSS 그라데이션으로 디자인한 포스터. 여행지 색(`destination.poster_color_from/to`), 큰 영문 도시명, 배지, 최저가를 담는다. `image_url` 컬럼은 비워 두었다가 나중에 사진으로 교체할 수 있다.
- **캐로셀**: 자동 넘김(기획전 6.5초, 베스트셀러 7.5초), 점에 진행 표시, 좌우 버튼, 키보드 방향키, 스와이프, 마우스를 올리면 멈춤, `prefers-reduced-motion` 에서는 자동 넘김 없음.
- **화면 전환**: 카드를 누르면 화면이 커지며 사라진 뒤 상세 페이지로 넘어간다(`data-transition`).
- 지구본은 CDN(globe.gl)에서 불러온다. 불러오지 못하면 안내 문구로 대체한다.
- 지구본 경로는 `GET /api/globe/routes` (인천 출발, 운항 가능한 도시마다 가장 빠른 1편, 직항 2점 / 경유 3점).

### 2-6. 투어 (`/tour`, `/tour/{tourId}`) — 11/20 추가

- **테마는 3가지만** 쓴다: 음식과 주류 투어 / 스포츠와 액티비티 투어 / 예술과 휴식 투어. 실제 여행 투어 상품을 참고한다. (예: 바르셀로나 → 축구 경기 관람 스포츠 투어)
- **개수**: 이달의 기획 3곳(로마·삿포로·케이프타운)과 베스트셀러 3곳(도쿄·로스앤젤레스·홍콩)은 3테마를 모두 만든다(18개). 나머지 해외 여행지(43곳, 블라디보스토크 제외 가정)는 도시당 1개이며, 그 도시의 유명한 특산물·관광상품을 웹에서 조사해 3테마 중 맞는 1개를 고른다.
- **기간 옵션**: 인천 기준 비행시간 6시간 이하는 2박3일·3박4일·6박7일, 6시간 초과는 6박7일·9박10일·13박14일. 투어 1개에 3가지 기간을 옵션으로 두고, 고르면 일정표·가격이 바뀐다.
- 목록: 테마 탭, 여행지 검색, 기간 필터. 상세: 일정표(일차별), 포함·불포함, 1인 가격, 장바구니 담기.
- 국내 투어(10개 도시 × 3테마 = 30개)도 같은 화면 구조를 쓴다.

### 2-7. 국내여행 (`/domestic`, `/domestic/{cityId}`) — 11/20 추가

- **도시 10곳**: 경주(경북), 강릉·속초(강원), 부산(경남), 제주, 전주(전라), 여수·순천·통영(남해), 단양. 출발지는 **서울·대전**.
- 흐름: 도시 선택 → 출발지 선택 → 이동편(버스·기차) 선택 → 투어·호텔 선택.
- 이동편은 도시 도착 기준 5개씩(총 50개, 출발지 서울·대전 포함, 종류는 버스·기차·시간대). **제주는 항공(김포→제주)을 포함**한다.
- 도시당 호텔 3개, 3테마 투어 3개.

### 2-8. 호텔 (해외 여행·국내여행 안) — 11/20 추가

- 해외 여행지당 3개, 이달의 기획·베스트셀러 6곳은 7개, 국내 도시당 3개 (총 201개). 이름·등급·가격은 가상.
- 가격은 **1박 기준과 전체 가격을 함께** 보여준다. 전체 가격 = 1박 × 박수. 투어를 먼저 고른 경우 그 박수를 쓰고, 호텔 단독으로 볼 때는 사용자가 박수를 고른다(기본 3박).

### 2-9. 크루즈(배 이동편) (해외 여행 안) — 11/20 추가

- 항구 도시 **7곳**만: 바르셀로나, 로마, 이스탄불, 리스본, 시드니, 밴쿠버, 호놀룰루.
- 해외 여행 상세에서 **항공편 / 크루즈 / 호텔** 탭으로 구분한다. 크루즈는 선박명·출항 항구·기항지·일정·객실 등급별 가격(가상)을 보여준다.

### 2-10. 고객문의 (`/support`) — 11/20 추가

| 기능 | 설명 |
|---|---|
| 문의 등록 | 로그인한 사용자가 제목·분류·내용을 등록 (분류: 항공·투어·호텔·크루즈·결제·기타) |
| 내 문의 | 내 문의 목록과 상세, 상태(접수/답변 완료) |
| 관리자 답변 | 관리자가 문의 목록을 보고 답변을 등록, 답변 시 상태가 '답변 완료'로 바뀜 |
| 제외 | FAQ, 공지사항 (이번 범위 아님) |

### 2-11. 팝업 이벤트 — 11/20 추가

- 메인에 들어오면 이벤트 팝업(모달)을 띄운다. 삐삐·거코와 이벤트 문구, QR 코드를 담는다. 닫기와 "오늘 하루 안 보기"를 제공한다.
- 관리자가 팝업을 등록하고 노출 기간과 노출 여부를 정한다. 기간 안에 있는 노출 팝업 1개를 표시한다.

### 2-12. QR 코드 — 11/20 추가

| 용도 | 설명 |
|---|---|
| 예약 확인·모바일 탑승권 | 결제가 끝난 예약마다 QR 생성. 스캔하면 예약 내용 확인 화면으로 이동 |
| 모바일 접속 | 메인·상품 화면의 QR을 스캔하면 같은 페이지가 휴대폰에서 열림 |
| 팝업·이벤트 참여 | 팝업의 QR을 스캔하면 이벤트 페이지로 이동 |
| 체크인·현장 확인 | 관리자가 예약 QR을 스캔(또는 코드 입력)해 입장·탑승을 체크인 처리 |

### 2-13. 장바구니·모의 결제 (`/cart`, `/checkout`, `/reservations`) — 11/20 추가

- 항공편·투어·호텔·크루즈·국내 이동편을 **장바구니에 담는다**(로그인 필요 가정). 인원과 출발일을 정한다.
- **결제하기** 버튼을 누르면 실제 결제 없이 "결제되었습니다" 안내를 보여주고 예약을 확정(상태 `PAID`)한 뒤 마무리한다.
- 내 예약 목록·상세에서 QR을 확인한다. (좌석 재고 차감·동시성 제어는 2단계)

### 2-14. 마스코트·오렌지 테마·모바일 — 11/20 추가

- **거코(코뿔소) + 삐삐(불 뿜는 병아리)**: SVG로 직접 그린다. 상단 로고, 팝업, 검색 결과 없음 같은 빈 화면, 404, 로딩 화면에 쓴다. 불꽃은 CSS 애니메이션.
- **오렌지 테마**: 포인트 색(링크·버튼·지구본 강조)을 하늘색에서 오렌지로 바꾸고 배경은 어두운 톤을 유지한다.
- **모바일**: 반응형과 모바일 전용 하단 탭 바.

## 3. 관리자 웹 (`/admin`, 사용자 웹과 분리)

| 메뉴 | 기능 |
|---|---|
| 로그인 | 관리자 전용 로그인 (사용자와 별도 계정 테이블) |
| 대시보드 | 회원 수, 항공편 수, 이달의 특별기획 상태 |
| 회원 관리 | 조회, 상태 변경(정지/복구) |
| 항공편 관리 | 항공편·경로·좌석등급 가격 등록/수정/삭제 |
| 여행지 관리 | 운항 가능/불가 상태와 사유, 설명, 이미지 |
| 특별기획 관리 | 기획전 등록, 대상 항공편과 특가 설정, 노출 기간 |
| 베스트셀러 관리 | 집계 기준 확인 (더미 → 실제 예약 집계) |
| 투어·국내여행·호텔·크루즈 관리 | 상품 등록/수정/노출 상태 (11/20 추가) |
| 팝업 관리 | 팝업 등록, 노출 기간, 노출 여부 (11/20 추가) |
| 고객문의 관리 | 문의 목록, 답변 등록 (11/20 추가) |
| 예약·체크인 | 예약 목록, QR 스캔 체크인 (11/20 추가) |

권한: `/admin/**` 는 `ROLE_ADMIN` 만 접근한다. 사용자는 `ROLE_USER`.

## 4. 지구본 효과 명세

| 항목 | 내용 |
|---|---|
| 데이터 | 공항 좌표(위도·경도)는 `airport` 테이블에서 가져온다. |
| 호(arc) | 출발과 도착 사이를 곡선으로 그리고, 선을 따라 움직이는 점으로 비행 연출 |
| 카메라 | 항공편 선택 시 출발과 도착의 중간 지점으로 지구본이 회전한다. |
| 경유 | 호 2개를 경유지에서 이어서 그린다. |
| 접근성 | 지구본을 불러오지 못하면 출발→도착 텍스트 경로로 대체한다. |
| API | `GET /api/flights/{id}/route` → 구간 목록(공항 코드, 좌표)을 JSON으로 반환 |
